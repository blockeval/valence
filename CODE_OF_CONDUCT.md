# Code of conduct

VALENCE is an academic open-source project. Participation requires respectful,
professional, and evidence-based collaboration.

Expected behavior includes:

- discussing technical disagreements without personal attacks;
- documenting assumptions, limitations, and uncertainty;
- crediting prior work and contributed ideas;
- protecting confidential vulnerability reports and unpublished data; and
- avoiding harassment, discrimination, intimidation, or exclusionary conduct.

Unacceptable conduct may result in comments, issues, pull requests, or access
being restricted. Report conduct concerns privately to the repository
maintainer through GitHub rather than posting sensitive details publicly.
