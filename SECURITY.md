# Security policy

## Supported version

Security and integrity fixes are accepted for the latest tagged release.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could enable code execution,
artifact tampering, dependency confusion, or misleading scientific results.
Use GitHub's **Report a vulnerability** / private security-advisory workflow.

Include:

- affected version or commit;
- operating system and Python version;
- reproduction steps;
- the smallest configuration and seed that trigger the problem;
- expected and observed behavior; and
- whether generated research artifacts may be affected.

VALENCE is research software and is not intended to secure production funds,
validator keys, or live blockchain infrastructure.
