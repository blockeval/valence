# Calibration profiles

Profiles under `calibration/profiles/` define reusable latency assumptions.
Every profile must identify whether it is:

- synthetic and illustrative;
- derived from published aggregate measurements; or
- based on raw empirical traces.

Measured profiles should document source, collection dates, locations,
preprocessing, units, missing-data handling, and redistribution rights.

Do not label a synthetic profile as observed Internet or mainnet behavior.
